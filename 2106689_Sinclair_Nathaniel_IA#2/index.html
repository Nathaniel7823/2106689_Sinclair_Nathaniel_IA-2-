What You Will Experience

Three focused tracks built around real browser standards, clean markup, and practical problem-solving.

01

Semantic & Accessible HTML5

Learn how meaningful document landmarks, screen-reader labels, and keyboard-first focus design make web applications usable by everyone.

02

Modern CSS3 Layout Craft

Build fluid interfaces that adapt from phones to widescreen monitors using Flexbox, CSS Grid, custom properties, and modern functional selectors.

03

Native JavaScript Engineering

Master client-side form checking with regular expressions, local file previews, state storage, and dynamic DOM rendering without external frameworks.

Opening Keynote • 9:30 AM

Featured Speaker: Jonatan Kristof

Jonatan is a front-end systems engineer and web accessibility educator who has spent the past eight years helping university teams and product startups ship fast, standards-compliant web applications.

At Coding Conf in Papine, Kgn, he will walk through real interface case studies showing how clean HTML structure, thoughtful CSS layout rules, and disciplined vanilla JavaScript keep projects reliable and easy to maintain.
